# 🌌 Dark Galaxy DevOps & Cloud Portfolio

A modern, high-performance personal portfolio website for **Nourhene Ayadi** — DevOps, Cloud & AI Engineer. 

Built with a deep cosmic design aesthetic featuring glassmorphism cards, glowing cyber-neon accents, a real-time system status terminal, and an interactive particle canvas background. Hosted on **Vercel** with continuous deployment triggered directly via **GitHub**.

## 🛠️ Tech Stack & Features

* **Design & Styling:** Custom CSS3 with glassmorphism UI, grid layout, and responsive media queries.
* **Animations:** Interactive HTML5 Canvas API generating a dynamic galaxy starfield.
* **Terminal Interface:** Built-in simulated command-line interface highlighting core engineer background metrics.
* **Continuous Delivery Pipeline:** Connected directly to Vercel for automated zero-downtime deployments on every `git push`.
