Graduation project

ACTIA Technologies // Client: Institut Molière

Conversational AI Platform for Institut Molière

Three-part generative-AI platform for language learning, defended 26/06/2026

A hybrid RAG chatbot combining ChromaDB semantic search with BM25 keyword retrieval via Reciprocal Rank Fusion, then cross-encoder reranking and query expansion for precision — served by Llama 3.3-70B with a local Ollama fallback for resilience. Alongside it, a speech-based corrective-feedback robot uses Whisper Large V3 for recognition and generates structured, Pydantic-validated pedagogical feedback spoken back through gTTS. A third component, an adaptive evaluation engine, uses Gemini 2.0 Flash with search grounding to generate curriculum-aligned questions and score learners automatically.

My role: Owned the system end-to-end — architecture, prompt engineering, backend (FastAPI), UI, and performance evaluation (latency and retrieval-quality benchmarking) — for a real external client.
